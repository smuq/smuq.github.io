# 🤖 AI Duo

Сравнитель двух ИИ в стиле Steam — страница **https://smuq.github.io**.

Вводишь **один** запрос — **одновременно** отвечают две модели Google Gemini.
Вход через Google (Google Identity Services).

## 📦 Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение в одном файле (стиль + логика) |
| `original-index.html` | Старая Firebase-версия (только локально, на GitHub не заливается) |
| `.gitignore` | Исключает `original-index.html` и `.vscode` из репозитория |
| `.vscode/settings.json` | Настройки VS Code (UTF-8) |

## ✅ Готово и работает

- Мобильная адаптивная вёрстка (фиксированная кнопка отправки, зоны касания ≥44px)
- Вход через Google (кнопки «🔐 Вход (A)» и «🔐 Вход (B)», раздельный статус «✓»)
- Одно поле запроса → параллельные ответы обеих моделей
- Реальные ответы на **бесплатном** Google Gemini API — карта не нужна
- Деплой на GitHub Pages: `git push`

## 💰 Бесплатно — Google Gemini (без карты)

Раньше для ответов нужны были **платные** ключи Qwen (DashScope) и DeepSeek.
Теперь обе панели работают через **Google Gemini Free Tier** — это бесплатно.

| Панель | Модель |
|---|---|
| A | `gemini-3.6-flash` |
| B | `gemini-3.5-flash-lite` |

### Как получить ключ (2 минуты, без карты)

1. Откройте **https://aistudio.google.com/apikey** (войдите в Google-аккаунт)
2. Нажмите **«Create API key»**
3. Скопируйте ключ вида `AIzaSy...`

### Как включить (30 секунд)

Ключ **скрыт из кода**, чтобы не светить его в исходниках сайта.

1. Откройте **https://aistudio.google.com/apikey** → «Create API key»
2. Скопируйте ключ (вида `AQ...` или `AIzaSy...`)
3. Откройте сайт, вставьте ключ в поле **«🔑 Бесплатный ключ Google Gemini»** и нажмите **«Сохранить»**

Ключ сохранится в вашем браузере (localStorage) и больше нигде храниться не будет.
Модели уже настроены: панель A — `gemini-3.6-flash`, панель B — `gemini-3.5-flash-lite` (проверены живыми запросами).

### Залить на GitHub Pages

```sh
git add index.html
git commit -m "Gemini: бесплатные ответы без карты"
git push origin main
```

## ⚠️ Важно

- Ключ в коде отсутствует намеренно: он вставляется на странице и хранится только в вашем браузере.
- Ключ из поля отправляется только в Google (и больше никуда).
- У бесплатного тарифа есть лимиты (запросов в минуту и в день) — для личного сайта их достаточно.

## 🔄 Запасной вариант (без ключа)

Если Gemini недоступен, можно подключить Pollinations.AI (`https://text.pollinations.ai/openai`) —
тоже бесплатно и без ключа, но анонимно действует ограничение по частоте запросов.
