# 🤖 AI Duo

Сравнитель двух ИИ в стиле Steam — страница **https://smuq.github.io**.

Вводишь **один** запрос — **одновременно** отвечают **Qwen** и **DeepSeek**.
Вход через Google (Google Identity Services) — отдельно для каждой модели.

## 📦 Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение в одном файле (стиль + логика) |
| `original-index.html` | Старая Firebase-версия (только локально, на GitHub не заливается) |
| `.gitignore` | Исключает `original-index.html` и `.vscode` из репозитория |
| `.vscode/settings.json` | Настройки VS Code (UTF-8) |

## ✅ Готово и работает

- Мобильная адаптивная вёрстка (фиксированная кнопка отправки, зоны касания ≥44px)
- Вход через Google: «🔐 Qwen Вход» и «🔐 DeepSeek Вход» (раздельный статус «✓»)
- Одно поле запроса → параллельные ответы обеих моделей
- Деплой на GitHub Pages: `git push`

## ⏳ Следующий шаг — API-ключи (продолжение завтра)

Сейчас модели отвечают демо-текстом, потому что в `index.html` стоят заглушки:

```js
const QWEN_API_KEY = "ВАШ_КЛЮЧ_QWEN";        // ~строка 684
const DEEPSEEK_API_KEY = "ВАШ_КЛЮЧ_DEEPSEEK"; // ~строка 688
```

Получить ключи:
- **Qwen:** https://bailian.console.aliyun.com → раздел **API-KEY** → создать (`sk-...`)
- **DeepSeek:** https://platform.deepseek.com → **API Keys** → Create new key (`sk-...`), нужен баланс ~$2

После вставки ключей залить на сайт:

```sh
git add index.html
git commit -m "Подключены API-ключи"
git push origin main
```

## ⚠️ Важно

API-ключи лежат в коде страницы и **видны всем**, кто откроет исходник сайта.
Это допустимо для личного сайта, но не делитесь страницей и следите за балансом.
